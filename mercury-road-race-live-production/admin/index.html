Timing Computers

Choose which physical computers can see this event in Mercury Bridge and which computer is allowed to send live results.

How to use these settings

Read / see event: makes this event appear in Mercury Bridge on that computer and lets the operator verify the selected destination. Read access by itself cannot change or publish results.

Publish results: allows Mercury Bridge on that computer to send result revisions for this event. Publish requires Read. Bridge safety gates and the exclusive writer lease still apply.

Writer lease: not a setting you turn on. When publishing is allowed, Bridge automatically uses the lease so only one computer can be the active writer at a time.

Credential Active / Disabled: controls whether that computer's saved Mercury Bridge credential can authenticate at all. Normally leave computers in service Active.

New code: creates a temporary 15-minute activation/replacement code for that physical computer. It does not grant event access and does not interrupt the existing credential unless the new code is redeemed.
